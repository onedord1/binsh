## About binsh

binsh is a cross-platform SSH client designed for DevOps engineers, system administrators, and developers who manage multiple servers. It provides:

- 🖥️ **Multi-server management** with groups and tags
- 🔐 **Secure credential storage** with encrypted vault
- 📁 **SFTP file management** with dual-pane interface
- ☁️ **Cloud provider integration** (AWS, GCP, Azure, etc.)
- 🛠️ **Quick Actions** for common server tasks
- 📊 **Real-time system metrics** and monitoring
- 🔄 **Port forwarding** management
- 📝 **Command snippets** library
